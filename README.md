# weldgrid

Weld encode/decode helpers for grid payloads in pipelines.

**Site:** https://theworker02.github.io/weldgrid/

## Install / run

```bash
git clone https://github.com/theworker02/weldgrid.git
cd weldgrid
node src/cli.js
node --test
```
